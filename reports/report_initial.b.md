# AIGC 合成人脸数据用于人脸识别数据扩充：实验报告

> 本报告的数字全部来自仓库内的结果文件，可在 `results/runs/*/metrics.json` 与
> `results/runs/w4-e4-comparison/comparison.json` 中逐项核对。
> 完整配方与 11 条踩坑记录见 [`W3-GENERATION.md`](W3-GENERATION.md)。

---

## 1. 问题

人脸识别模型依赖**大规模身份标注数据**。公开学术数据集（LFW 等）规模有限、身份分布失衡，
而采集新身份涉及隐私与授权。本项目检验一个具体问题：

> **用身份保持的生成模型为已有身份合成更多照片，能否提升识别模型的性能？**

拆成两个可测量的子问题：

| | 问题 | 对应实验 |
|---|---|---|
| Q1 | 合成数据加入训练集后，识别性能变好吗？ | **E1 vs E4a/E4b** |
| Q2 | 现成的身份保持生成方案，质量够用吗？ | **生成器对照（W3）** |

---

## 2. 方法

### 2.1 流水线

```
LFW 原始图 ──对齐(112×112 ArcFace)──┐
                                    ├─→ 生成(plusv2) → 筛选 → E4 训练 → 评测
      96 身份 / 3590 张 ────────────┘
```

### 2.2 数据

| 项 | 值 |
|---|---|
| 数据源 | LFW：5749 身份 / 13233 张 |
| 训练身份 | **96 个**（按图片数取前 96） |
| 训练图片 | **3590 张** 112×112 对齐裁剪 |
| 类别失衡 | 最大类 538 张（12.4%），最小类 23 张（**23:1**） |
| **已知局限** | LFW 官方 6000 对覆盖 **4281 个身份**，其中**包含全部 96 个训练身份** → **训练/测试泄漏不可避免**（第 5 节给出量化） |

### 2.3 生成配方（最终版）

| 项 | 值 |
|---|---|
| 适配器 | **IP-Adapter-FaceID-plusv2**（`ip-adapter-faceid-plusv2_sd15.bin`）|
| **`shortcut`** | **True**（`s_scale=1.0`）—— 为 False 时感知器输出会**覆盖** ID 分支 |
| CLIP 分支 | `hidden_states[-2]`；负例 = **对全零图像编码**；输入 `norm_crop(..., 224)` |
| ID 分支 | `buffalo_l` 的 `normed_embedding`，**多张参考图平均** |
| 结构参考 | 每身份最多 **2 张**（质量闸门 + 主动挑差异最大的第二张），**轮换使用** |
| 底模 / VAE | SD1.5 / `sd-vae-ft-mse`；DDIM，30 步，guidance 7.5，IP scale 1.0 |
| 规模 | 96 身份 × 10 张 = **960 张**（58 分钟）|

### 2.4 筛选

**质量地板 0.45 + 冗余剪枝**（迭代删除与同身份其余图最相似的那张），每身份保留 ≤8 张。

> ⚠️ **不能按 `id_sim` 排名取前 N**：实测这样选出的 8 张比不剪枝的 10 张**还要同质**
> （CLIP 结构相似度 0.7049 vs 0.7003），因为被删的恰是为多样性特意挑的第二参考图所生成的图。
> 冗余剪枝则降到 0.6846。

**筛选结果**：960 → **755 张**（均值 `id_sim` **+0.6154**，最小 +0.4505，每身份 5~8 张）

### 2.5 训练与评测

| 项 | 值 |
|---|---|
| 模型 | iresnet18（62.6M）+ ArcFace(m=0.5, s=64) |
| 优化 | SGD lr=0.1（余弦退火）+ **梯度裁剪 5.0** + **warmup 3 轮** |
| 数据集 | E1：real 3590；**E4a：real 3590 + synth 755（17.4%）**；E4b：+448（11.1%）|
| 评测协议 | LFW 官方 6000 对（10 折）、filtered 子集、**held-out 大样本（125,191 对）** |
| 指标 | `accuracy@best`（测试集扫阈值）+ **`TAR@FAR=1e-3`**（阈值只由 impostor 决定）|
| 重复 | **3 个随机种子** |

> **为什么两个指标都报**：`accuracy@best` 在测试集上扫阈值，对弱模型偏乐观；
> `TAR@FAR` 更接近实际部署。本项目的教训是二者的结论**强度可以差一个数量级**。

## 3. 结果

### 3.1 生成质量（W3）

| 方案 | `id_sim` 均值 | 最小值 |
|---|---|---|
| base FaceID | +0.3891 | +0.2035 |
| plusv2（官方配方） | +0.5138 | +0.4320 |
| **plusv2 + 多参考平均（采用）** | **+0.6084** | **+0.5273** |
| plusv2 + Realistic Vision V6 | +0.3999 | +0.2836 |

> 参照：**同一个人两张真实照片 = 0.745**；**不同人 < 0.25**。
> 最终配方把身份相似度提升 **56%**，并使**最差样本**从 0.20 提到 0.53 ——
> 对训练数据而言，下限比均值更关键。

### 3.2 E4 对照（3 种子均值 ± 标准差）

| 协议 | 指标 | E1 纯真实 | **E4a 真实+合成** | Δ | Welch t | 判定 |
|---|---|---|---|---|---|---|
| official | accuracy | 0.8812 ± 0.0032 | **0.8899 ± 0.0026** | +0.0086 | **+3.59** | ✅ **显著** |
| official | TAR@1e-3 | 0.4208 ± 0.0040 | 0.4548 ± 0.0321 | +0.0340 | +1.82 | ❌ |
| filtered | accuracy | 0.8727 ± 0.0039 | **0.8819 ± 0.0028** | +0.0093 | **+3.35** | ✅ **显著** |
| filtered | TAR@1e-3 | 0.3402 ± 0.0046 | 0.3789 ± 0.0366 | +0.0387 | +1.82 | ❌ |
| **held-out（无泄漏）** | accuracy | 0.8693 ± 0.0035 | **0.8775 ± 0.0005** | +0.0082 | **+3.98** | ✅ **显著** |
| held-out（无泄漏） | TAR@1e-3 | 0.3108 ± 0.0184 | 0.3289 ± 0.0095 | +0.0181 | +1.52 | ❌ |

**参考点**：零样本 `buffalo_l` 在 held-out 协议上 TAR = **0.9989**、accuracy = **0.9993**
—— 说明协议可解，也说明 96 身份训练的模型离预训练模型仍有很大距离。

### 3.3 结论

**✅ 站得住**：加入 755 张合成图（占 17.4%）使 LFW **accuracy 提升 +0.0082~+0.0093**，
**在三个协议、三个种子上方向完全一致，Welch t = 3.35~3.98**（n=3 时双侧 5% 临界值约 3.18）。

**⚠️ 不能宣称**：`TAR@FAR=1e-3` 呈正向趋势（+0.018~+0.039），但**未达显著**。
逐种子的配对 bootstrap（held-out 协议，125k 对）显示：

| seed | Δ TAR | 90% 区间 | P(Δ>0) |
|---|---|---|---|
| 0 | **−0.0119** | [−0.0273, +0.0026] | 8.7% |
| 1 | **+0.0307** | [+0.0151, +0.0475] | 99.9% |
| 2 | **+0.0355** | [+0.0144, +0.0554] | 100.0% |

**两个种子强阳性、一个种子无效应；种子间标准差 0.026 > 效应量 0.018。**
即：合成数据对 TAR 的增益**真实存在但不稳定**，3 个种子不足以判定。

**❌ 反而更差**：Realistic Vision V6 底模在两种适配器下都明显更差（0.3999 / 0.0428），
确认与 FaceID 适配器不兼容。

## 4. 方法学发现（本项目的主要副产品）

### 4.1 官方 LFW 协议**高估**了 TAR 效应近一倍

官方协议 TAR 增益 +0.034，**无泄漏协议只有 +0.018**。

原因：官方 6000 对覆盖 4281 个身份，**包含全部 96 个训练身份** —— 模型见过这些脸。
我们用 LFW 的 **5653 个未见身份**构造了 125,191 对（11,381 same / 113,810 diff），
**身份与训练集交集为 0**，量化了这一偏差。

### 4.2 评测分辨率 vs 训练种子：瓶颈会转移

| | 官方协议 | held-out 协议 |
|---|---|---|
| 非同类对 | 3,000 | **113,810** |
| FAR=1e-3 下的 impostor | **3** ❌ | **113** ✅ |
| TAR 的 bootstrap 标准误 | ~0.065 | **~0.005** |

把分辨率提上去之后，**剩余的不确定度全部来自训练种子**（E1 的三个种子跨度 0.2946~0.3308）。
**继续堆评测集已无意义，只能加种子。**

### 4.3 两个指标可以给出不同强度的结论

`accuracy@best` 提升 +0.009（t≈4，显著），`TAR@FAR=1e-3` 提升 +0.018~0.034（t≈1.5~1.8，不显著）。
若只报前者，会严重高估这项技术在实际部署中的价值。

### 4.4 训练不稳定性的定位与修复

5 次训练里崩了 2 次：某一类的分类头权重爆炸成为"吸引子"，`loss` 卡在 ~16、`train_acc` 恒为 0。
**同数据同配置，只差随机流**。加入**梯度裁剪 + LR warmup** 后 6 次零崩，
且收敛更好（E1 的 `train_acc` 0.9880 → 0.9992）。
守门指标：**分类头权重范数的「最大/中位数」比值**（健康 1.37~1.45，崩塌 3.30）。

---

## 5. 局限

1. **训练/测试泄漏不可避免**：LFW 官方对子覆盖 4281 个身份，包含全部 96 个训练身份。
   已用无泄漏的 held-out 协议量化（效应减半），但官方数字仍偏乐观。
2. **TAR 未达显著**，且**种子方差大于效应量**。按当前分布外推，需要约 **8 个种子/方案**
   才有望双侧显著。
3. **合成占比只测了 17.4% 与 11.1%**，未做占比扫描，"加多少合适"未回答。
4. **只测了 iresnet18 一个架构**，结论未必迁移到更大的骨干网络。
5. **合成数据规模有限**（755 张 vs 3590 张真实图），且每身份最多 8 张。
6. **数据规模小**：96 个身份、3590 张图，远小于真实人脸识别训练集
   （这也是自研模型 TAR 仅 0.33、而零样本 buffalo_l 达 0.9989 的主因）。
7. **生成质量仍有上限**：`id_sim` 0.6154 虽已高于"不同人"上限，但低于同人真实照片的 0.745。

## 6. 复现

```bash
# 1) 数据：下载 LFW 并对齐
python scripts/download_data.py --config configs/data/lfw.yaml
python scripts/build_dataset.py

# 2) 参考基线 E0（零样本 buffalo_l）
python scripts/evaluate.py --exp-id e0-buffalo_l-lfw

# 3) 生成（需先下 plusv2 权重，约 2.5 GB）
python scripts/download_data.py --config configs/data/ipadapter_plusv2.yaml
python scripts/generate_plusv2.py --per-identity 10 --max-refs 2

# 4) 对齐 + 筛选
python scripts/align_synth.py
python scripts/filter_synth.py --exp-id syn-plusv2 --threshold 0.45 --keep-per-identity 8

# 5) 训练（E1 与 E4a，各 3 个种子）
python scripts/train.py --exp-id e1-real-only-seed0 --exp configs/exp/e1-real-only-seed0.yaml --seed 0
python scripts/train.py --exp-id e4-real-plus-synth-seed0 --exp configs/exp/e4-real-plus-synth.yaml --seed 0
# ... seed1 / seed2 同理

# 6) 评测（官方协议 + 无泄漏协议）
python scripts/evaluate.py --exp-id e4-real-plus-synth-seed0 --ckpt F:/aigcfr/ckpt/e4-real-plus-synth-seed0/best.pth
python scripts/build_verify_protocol.py
python scripts/evaluate_heldout.py --exp-id e4-real-plus-synth-seed0 --ckpt F:/aigcfr/ckpt/e4-real-plus-synth-seed0/best.pth

# 7) 汇总统计
python tools/w4_compare.py
```

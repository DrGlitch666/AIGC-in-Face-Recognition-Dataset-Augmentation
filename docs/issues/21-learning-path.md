## 背景 / 为什么做这个

项目由两人从零开始做，**学习不是额外负担，而是项目的一部分**。但零基础自学最容易出两种问题：

1. **看了很多，用不上**——不知道学的东西对应项目哪一步，看完就忘；
2. **跳过基础直接抄代码**——不懂评测协议就去跑实验，跑出来的数字是错的还不知道。

所以学习线也要有**路线、有动手、有自测、有产出物**，而不是"有空就看看"。

完整的六阶段路线（概念 → 材料 → 动手 → 自测，含答案要点）在 [`LEARNING.md`](../LEARNING.md)。

## 目标

两人各自走完 L0~L5，并在项目全程持续 L6；每个阶段的产出物都落到仓库里，而不是停留在"我看过了"。

## 任务清单

- [ ] **排节奏**：把六个阶段映射到 Sprint 上（建议每个 Sprint 开始前集中学对应阶段），写进本 Issue 评论
- [ ] **L0 建立直觉**（2~3 小时，两人各做一遍）
  - [ ] 装好 insightface，取 5 组图片（3 组同人 + 2 组异人）
  - [ ] 打印 embedding 维度、手算一次余弦相似度并与库结果对比
  - [ ] 画出 5 组图片的相似度矩阵并贴到本 Issue
  - [ ] 回答 L0 的 4 道自测题
- [ ] **L1 人脸识别基础**（1~2 天）
  - [ ] 跑通预训练模型在 LFW 上的零样本评测（与 {{#05-zeroshot-baseline}} 合并）
  - [ ] 手动实现一次 10 折协议，并与"全量选阈值"的版本对比，解释差异
  - [ ] 画出同人/异人相似度分布直方图，标出重叠区
  - [ ] 回答 L1 的 6 道自测题
- [ ] **L2 生成模型基础**（2~3 天）
  - [ ] 用 `diffusers` 生成 4 张 512×512 人脸，记录耗时与显存峰值（与 {{#09-unconditional-generation}} 合并）
  - [ ] 固定 seed 复现一次；换 4 个 seed 观察哪些属性变化
  - [ ] 手绘"四种条件注入方式"的对照表并解释各自控制什么
  - [ ] 回答 L2 的 6 道自测题
- [ ] **L3 身份保持生成**（2~3 天）
  - [ ] 对 1 个身份生成 4 张，人工判断像不像（与 {{#10-identity-preserving-generation}} 合并）
  - [ ] 计算并画出「生成图 vs 参考图」「生成图 vs 生成图」的相似度热力图
  - [ ] 做一次身份条件强度的对比，亲身体会"保真 vs 多样性"的取舍
  - [ ] 回答 L3 的 5 道自测题
- [ ] **L4 实验方法与统计**（1~2 天）
  - [ ] 手算一次 TAR@FAR，再用代码验证（与 {{#07-evaluator}} 合并）
  - [ ] 用 3 个 seed 跑同一配置，记录并计算标准差，体会"同一配置能差多少"
  - [ ] 回答 L4 的 6 道自测题
- [ ] **L5 伦理、法律与许可**（半天）
  - [ ] 逐条核对本项目用到的数据集与模型许可，做成表格（与 {{#18-ethics-and-release}} 合并）
  - [ ] 检查仓库里没有数据文件
  - [ ] 回答 L5 的 4 道自测题
- [ ] **L6 论文精读（持续）**：每周 2 篇，按 [`LEARNING.md`](../LEARNING.md) L6 的顺序（必读 8 篇 + 选读）
  - [ ] 摘要卡写入 `docs/BACKGROUND.md`（与 {{#04-background-survey}} 合并验收）
- [ ] **每周互讲 15 分钟**：两人互相讲上周学的内容，对方提问；讲不清的地方记下来重学
- [ ] **自测答案记录**：把每阶段自测题的作答写在 `docs/learning-notes.md`（或本 Issue 评论），**先自己答再看答案要点**

## 新手提示 / 卡住了怎么办

- **学习必须挂靠产出物**：每一段学习都要能回答"这对应项目哪一步、产出什么文件"。答不上来就说明这段可以跳过。
- **自测题先自己做**再看答案要点——直接看答案等于没学。
- 看不懂论文的数学推导就跳过：**先能用、再能解释、最后才是能推导**，本项目只需要前两层。
- 两人进度不一样很正常：**快的那个不要等**，但每周互讲必须做，因为"讲出来"是最有效的检验。
- **降级方案**：时间紧时优先完成 L0、L1、L4（理解数据、评测与统计），L2/L3 可以在实际做生成任务时边做边补。

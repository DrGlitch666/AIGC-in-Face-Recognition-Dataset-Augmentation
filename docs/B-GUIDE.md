## 5. 与 B 相关的踩坑（**别重蹈**）

| 坑 | 教训 |
|---|---|
| `tar_at_far(labels, scores, far)` 参数写反 | **不报错**，`labels==1` 会去筛"分数恰好等于 1.0"的样本，静默返回 `nan`。排查了很久 |
| 每折 TAR@1e-3 不可解 | 每折只有 300 个非同类对，期望 impostor 数 0.3 → 按折算一定是 `nan`。**这不是 bug，要断言它** |
| `det_size` 用 640 评生成图 | 一张脸都检不出 → 曾把"可评分 0/N"误判成"生成的图崩坏"。**生成图/对齐图要用 320** |
| 幸存者偏差 | 在错误 det_size 下"能检出的图恰好是更通用的脸"，据此得出的"改进 10 倍"完全不可信。**指标口径一改，之前所有对比都要重测** |
| 手抄数字 | 这条写进规矩一 |
